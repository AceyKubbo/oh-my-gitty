# Oh My Gitty UI 设计系统

简体中文 | [English](ui-design-system.en.md)

## 设计方向

以参考图的「终端监控台」为视觉基准：黑色画布、细线分区、信息密度优先、颜色只用于表达状态和数据。界面不使用大面积渐变、厚重阴影或高圆角卡片。

## 色彩

语义 token 分暗/亮两套主题，状态色在两套主题中保持一致。下表为暗色主题（默认）的基准值；亮色主题见 `src/styles.css` 的 `[data-theme=light]`。

| Token | 暗色值 | 用途 |
| --- | --- | --- |
| `--bg` | `#1b1b1b` | 应用画布、代码区 |
| `--panel` | `#222222` | 面板、卡片 |
| `--panel-2` | `#292929` | 菜单、输入框、悬浮层 |
| `--border` | `#464646` | 默认分隔线 |
| `--border-strong` | `#5b5b5b` | 聚焦、拖拽和强调边界 |
| `--text` | `#f0f0f0` | 正文与主要数值 |
| `--text-head` | `#dddddd` | 标题 |
| `--text-dim` | `#b5b5b5` | 辅助信息、路径、时间 |
| `--accent` | `#7d5cdf` | 选择态、AI、分支和提交动作（默认紫色） |
| `--orange` | `#ff9d00` | 运行、端口和活动数据 |
| `--green` | `#00d084` | 成功、已完成、运行中 |
| `--red` | `#ff6b6b` | 冲突、删除、危险操作 |

## 主题与强调色

- 明暗两套主题默认跟随系统偏好，也可在设置中切换（`data-theme`）。
- 强调色与主题正交：7 种配色（紫 / 浅蓝 / 深蓝 / 黄 / 浅绿 / 深绿 / 红）分别定义暗/亮两套 `--accent` 值，见 `src/styles.css` 的 `[data-accent]` 段落；设置弹窗里的色块仅作预览。
- 状态色（成功 / 冲突 / 运行等）不随主题与强调色改变。

## 字体与层级

- 正文使用系统无衬线字体，保证中文阅读。
- 数值、路径、命令、状态标签和分组小标题使用 `ui-monospace`。
- 页面标题 14–16px；分组标签 11–12px，使用大写/字间距表达层级；正文 12–13px。
- 数字使用白色高对比，解释文字降低到 `--text-dim`，避免所有内容争抢注意力。

## 布局与组件

- 页面采用 1px 分隔线和 8/12/16/24px 间距节奏。
- 所有按钮、输入控件、标签、徽标和卡片统一使用直角，避免传统 SaaS 卡片感。
- 交互控件默认透明或底色，hover 只提升一个灰阶；选中态用强调色左边线/描边，不使用大面积强调色填充。
- 数据卡片保持边框，不使用阴影；图表网格线使用低对比灰色。
- 破坏性操作必须使用红色并保留现有二次确认流程。

## 页面应用

- 总览：KPI 三列、活动与类型统计、项目卡片和运行状态；强调色（默认紫色）表达提交/AI，橙色表达运行/端口。
- 项目页：顶部项目身份与分支，操作栏保持紧凑；暂存、修改、冲突、历史使用线性分组。
- Diff/日志：使用更深的代码画布，增删行分别使用绿色/红色低透明度底色。
- 设置与确认弹窗：跟随当前主题的画布底色、细边框、直角，危险说明只在不可逆动作时展示。
